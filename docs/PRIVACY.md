# Privacy policy – Launcher Tags Sync

*Applies to the Android app `cz.jancejka.launchertagssync` and the command-line tool. Last
updated 2026-11-23.*

Launcher Tags Sync does **not collect, transmit or share any data**.

* The app has no internet permission and contains no analytics, advertising or crash
  reporting libraries.
* It only reads backup files that you select yourself and writes the files you choose to
  save, through the Android system file picker.
* To support two-way sync it stores, in its private app storage only: the last agreed list of
  app aliases per app package (the sync state) and a history of runs with counts (no texts,
  no app names). This data never leaves your device and is excluded from Android cloud
  backups and device transfers. Uninstalling the app or using “Reset two-way sync” removes it.

Contact: open an issue at https://github.com/Cuchulain/launcher-tags-sync/issues.
